# 论文精读笔记

## 1. 基本信息

- 标题：产业升级背景下新质生产力赋能江苏省经济增长的投资路径研究——以无锡市为例
- 作者：尚倩倩
- 年份：2026
- 会议/期刊：中国商论

### 摘要

摘 要：以科技创新为核心动力的新质生产力是推动区域经济实现高质量发展的关键引擎。基于投资结构优化与全要素生产率提高的内在理论逻辑，本文系统分析了新质生产力赋能无锡经济增长的作用机理与具体路径。研究结果表明，无锡市在产业升级投资、绿色技术投资以及数字新基建投资三大领域已取得阶段性成效，但也面临着产业结构失衡问题突出、绿色转型成本压力较大、数字基础设施供需脱节等现实困境。基于此，本文提出产业升级投资需聚焦存量提质与增量布局协同推进、绿色技术投资要降低转型成本与增强内生动力、数字新基建投资则应探索化解技术迭代风险与转化应用瓶颈等针对性投资路径，以期为无锡市优化投资结构、释放新质生产力活力、推动经济高质量发展提供理论支持与实践参考。

## 2. 论文解决的问题

新质生产力赋能无锡经济增长的投资路径优化问题，具体包括产业升级投资、绿色技术投资和数字新基建投资的结构失衡、转型成本高、供需脱节等困境。

## 3. 背景与动机

投资结构优化对全要素生产率提高至关重要，无锡处于产业转型升级关键节点，传统投资驱动模式局限性凸显，亟需引导资本流向高技术、高附加值领域，释放新质生产力活力。

## 4. 核心方法

本文从产业升级投资（存量提质与增量布局协同）、绿色技术投资（降低转型成本与增强内生动力）、数字新基建投资（化解技术迭代风险与转化应用瓶颈）三个维度，系统分析投资驱动经济增长的内在机制，并结合无锡实际提出具体路径。

## 5. 创新点总结

- 将新质生产力与投资结构优化相结合，提出“存量提质+增量布局”协同推进的产业升级投资路径
- 针对绿色转型成本高、回报周期长的问题，提出降低转型成本与增强内生动力的绿色技术投资路径
- 针对数字技术迭代风险，提出化解技术迭代风险与转化应用瓶颈的数字新基建投资路径
